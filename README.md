# 멍냥이 동산

강아지, 고양이, 기니피그가 알아서 놀고 쉬는 시골 동산을 구경하며 가끔 손길을 보태는 힐링 웹 게임이에요.
혼자 쉬는 **내 동산**과, 다른 돌보미들이 단짝 한 마리씩 데리고 모이는 **마을 동산(실시간)**이 있어요.

## 무엇이 들어 있나요

- **내 동산**: 식구 12마리(태리, 숙희, 두부, 만복, 짱아, 꽃님, 또치, 총총이, 명랑이, 월이, 수리, 차차), 기니피그 놀이터(뽀에버, 프레디), 동네 친구들, 찾아오는 손님, 할머니·할아버지, 손자 태은이
- **내 돌보미(아바타)**: 땅을 누르면 걸어가고, 앉고, 손 흔들고, 쓰다듬고, 물건을 놓아요. 꾸밀 수 있어요.
- **하루와 날씨**: 12분이 하루, 소나기(비 피하기·천막)와 무지개, 물고기·나비·참새·다람쥐·별똥별, 노을 모임·고양이 집회
- **할머니·할아버지**: 낚시, 텃밭 농사, 아궁이 요리, 농막·원두막에서 쉬기, 아이들 쓰다듬기, 아침 7시부터 활동하고 밤 9시 반에 들어가 10시 전 취침, 비 오면 집으로
- **아궁이 노래**: 아궁이에 불을 지피면 강아지·고양이들이 아궁이 앞에 모여 다 같이 노래(태은이·기니피그도 따라 불러요)
- **손자 태은이**(여름 방학 손님): 할머니·할아버지와 낚시·텃밭·밥 먹기·이야기, 강아지와 달리기, 고양이와 강아지풀 놀이, 기니피그 풀 주기, 잠자리채 나비 잡기, 물수제비, 깡충 뛰기, 툇마루 낮잠, 돌보미에게 말 걸기
- **계절**: 한여름(풋감, 푸른 벼) — 태은이의 여름 방학과 맞춤
- **사진 도감 28가지**: 아궁이 합창, 태은이와 달리기, 풀 주는 태은이, 마음을 연 명랑이, 월이 이모와 총총이 추가
- **고양이 성격**: 명랑이는 경계심이 많아 ♥♥ 전엔 물러나고 그 뒤엔 나만 따라다님, 월이는 금방 친해지고 먼저 다가옴, 총총이는 월이 이모를 따라다님
- **모으기**: 손님 도감, 사진 도감(28가지 순간), 앨범, 선물함, 일기, 단짝 비밀
- **쉬어 가기**: 구경 모드, 🌙 틀어 두기(빗소리·자연 소리, 꺼짐 타이머)
- **마을 동산**: 스티커·정해진 말 대화, 단체 사진, 함께 쓰다듬기, 매일 밤 9시 반딧불이 모임, 👥 함께 있는 사람, 📅 다음 날 만날 약속 잡기
- **그 밖**: ❔ 이용 가이드(화면 캡처 포함), 📦 기기 옮기기(이어하기 코드), 휴대폰 화면 맞춤

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 게임 전체 (그림, 동물, 소리, 저장, 마을 동산까지 한 파일) |
| `config.js` | Supabase 주소와 공개 키를 넣는 설정 파일 |
| `supabase.sql` | Supabase에 한 번 실행하는 표·보안 규칙 (저장, 신고) |
| `guide/` | 게임 안 ❔ 이용 가이드에 들어가는 화면 캡처 (index.html과 같은 폴더에 함께 올려 주세요) |
| `README.md` | 이 안내서 |

`config.js`를 비워 두면 서버 없이도 돌아가요.
- 저장: 이 브라우저에만 남아요.
- 마을 동산: 같은 브라우저에서 탭 두 개를 열었을 때만 서로 보이는 **테스트 모드**예요.

## 1. Supabase 준비 (한 번만)

1. [supabase.com](https://supabase.com)에서 새 프로젝트를 만들어요.
2. **SQL Editor**에 `supabase.sql` 내용을 붙여 넣고 **Run** 해요.
3. **Authentication** 설정에서 **Anonymous sign-ins(익명 로그인)**를 켜요.
   - 돌보미가 이메일 없이 들어오게 하는 설정이에요.
   - 메뉴 이름은 Supabase 화면 개편에 따라 조금 다를 수 있어요.
4. **Project Settings → API**에서 아래 두 값을 복사해요.
   - Project URL
   - anon public key

## 2. config.js 채우기

```js
window.DONGSAN_CONFIG = {
  supabaseUrl: 'https://(내 프로젝트).supabase.co',
  supabaseAnonKey: '(anon public key)',
  maxPerRoom: 8
};
```

- anon 키는 공개돼도 되는 키예요.
- 각자 자기 저장 데이터만 읽고 쓸 수 있도록 `supabase.sql`의 RLS 규칙이 막아 줘요.
- **service_role 키는 절대 넣지 마세요.**

## 3. GitHub Pages에 올리기

1. GitHub에 새 저장소를 만들어요. 예: `meongnyang-dongsan`
2. `index.html`, `config.js`, `supabase.sql`, `README.md`와 **`guide` 폴더**를 저장소 맨 위(루트)에 올려요.
3. 저장소 **Settings → Pages**에서 아래처럼 설정해요.
   - Source: `Deploy from a branch`
   - Branch: `main` / `/(root)`
4. 잠시 뒤 `https://(아이디).github.io/meongnyang-dongsan/` 주소로 열려요.

## 4. 확인하기

- **내 동산**
  - 처음 들어오면 태리가 다가오고 숙희 누나가 뒤따라와요. 조금 뒤 할머니가 인사해 주세요.
  - 새로고침해도 하트, 별명, 일기가 남아 있으면 서버 저장이 된 거예요.
- **마을 동산**
  - 오른쪽 위 🏘️ 마을 버튼 → 단짝 고르기 → 놀러 가기
  - 다른 기기(휴대폰 등)에서도 들어가 보면 서로의 단짝이 보여요.

## 마을 동산은 이렇게 돌아가요

- **방**
  - 방마다 최대 `maxPerRoom`명이에요.
  - 차면 다음 방(마을 2번, 3번…)으로 자동으로 들어가요.
- **마을 시간 맡기**
  - 먼저 들어온 사람의 화면이 "마을 시간"을 맡아요. 동네 친구들 움직임과 작은 사건을 계산해서 나눠 줘요.
  - 그 사람이 나가면 다음 사람이 이어받아요.
- **마을 시계**: 실제 시각에 맞춰 흘러서 모두에게 같은 시간대가 보여요. 12분이 하루예요.
- **대화**: 감정 스티커와 정해진 문구만 써요. 자유 입력은 없어요.
- **이름표**: 정해진 단어 조합으로만 만들어져요. 🔄 버튼으로 다시 뽑을 수 있어요.
- **물건**: 한 사람당 2개까지만 놓을 수 있고, 연속으로 놓을 수 없게 짧은 대기 시간이 있어요.
- **함께할 때만 생기는 일**
  - 두 사람이 같은 동네 친구를 3초 안에 함께 쓰다듬으면 특별한 반응이 나와요.
  - 단짝끼리 가까이 가면 코 인사를 해요.
  - 📸 단체 사진: 모두가 함께 모여 사진을 찍어요. 사진은 각자 앨범에 저장돼요.

### 조절할 수 있는 값 (index.html 안)

- `netTick` 함수
  - 내 단짝 위치 전송: 움직일 때 0.25초마다, 멈춰 있을 때 2초마다
  - 마을 시간을 맡은 사람의 동네 친구 위치 전송: 0.34초마다
- Supabase 무료 구간에는 동시 접속 수와 메시지 수 한도가 있어요. 사람이 많아지면 위 간격을 늘리거나 요금제를 확인하세요.

## 서버 없이 마을 동산 테스트하기

`config.js`를 비워 둔 채 페이지를 열고, 🏘️ 마을 → 놀러 가기를 누르면 테스트 모드로 열려요.
같은 브라우저에서 **탭을 하나 더 열어** 같은 주소로 들어가면 두 탭이 서로 보여요.

## 운영하며 할 일

- **신고 확인**: Supabase 대시보드 → Table Editor → `reports` 표에서 봐요. (누가, 누구를, 어떤 이유로, 몇 번 방에서)
- **사람이 많아지면**: `config.js`의 `maxPerRoom`과 위의 전송 간격을 조절해요.

## 나중에 할 일

- **신고 확인 도구**: 신고는 Supabase `reports` 표에 쌓여요. 지금은 대시보드 Table Editor에서 직접 봐요.
- **계정 로그인**: 지금은 ⚙️ 설정 → 📦 기기 옮기기(이어하기 코드)로 옮겨요. 나중에 Google 같은 로그인을 붙이면 자동으로 이어져요.
- **사계절, 동산 꾸미기**

## 공개 전에 확인하세요

- **게임물 등급분류**: 무료로 공개하는 게임도 대상이 될 수 있어요. 게임물관리위원회 기준을 확인하세요.
- 지금 구조는 이름, 이메일 같은 개인정보를 받지 않아요. 익명 ID와 게임 진행 데이터, 신고 기록만 저장해요.
